# Additional-functions-for-Tree_puzzles

Additional features
- Trees now can be clicked to have apples
- 0 files/columns now have water
- Tents on water now are floating tents
- OST added
- '+ FUN button added to activate and desactivate features

![Demo of features](https://i.imgur.com/9Jebz7Q.png)

## 📦 Installing the "ThermoGift Fun button" Script

Follow these steps to add the extra functionality to the game.

### 1. Install Tampermonkey
First, you need to install the Tampermonkey extension for your browser.

[![Tampermonkey](https://img.shields.io/badge/Install-Tampermonkey-green?style=for-the-badge&logo=tampermonkey)](https://www.tampermonkey.net/)

### 2. Install the Script
Once Tampermonkey is installed, click the button below. The extension will ask you if you want to install it – confirm and you're ready to go.

<a href="https://raw.githubusercontent.com/f-calderon-ui/Additional-functions-for-Tree_puzzles/main/ThermoGift%20Fun%20button-1.0.user.js">
  <img src="https://img.shields.io/badge/Install_Script-Automatically-blue?style=for-the-badge&logo=javascript" alt="Install Script">
</a>

> **Note:** If the button doesn't work, you can also right‑click it, copy the link, and paste it into the "Utilities" tab inside the Tampermonkey dashboard, under "Install from URL".

### 3. Afterinstall
If the button doesn't display, rechargue the screen.
